# Project session reference

The creator describes the idea in ordinary language. Before changing files, read the workspace instructions and the project's own records.

For a project in this repository:
- Work only in projects/<project-id>/ unless the creator asks for a shared maintenance change.
- Read project.json, PROGRESS.md, CHANGELOG.md and the current source files.
- Resume an existing work/ or experiment/ branch when possible.
- Save meaningful progress to GitHub before ending.
- Keep experiments on branches and open a pull request only when the work is complete.
- Never commit directly to main.

The workspace-level instructions are authoritative: CHATGPT_INSTRUCTIONS.md and governance/SESSION_PLAYBOOK.md.
