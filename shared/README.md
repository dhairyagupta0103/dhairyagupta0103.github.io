# Shared resources

Put reusable, non-sensitive code and assets here so projects do not recreate the same utilities.

Before adding a helper, search this folder and existing projects. Prefer small, dependency-free utilities with a short README or example.

Projects may reference root-hosted shared assets using paths such as ../../shared/design-tokens.css. Keep shared resources backward-compatible where practical. If a change could break several projects, treat it as a maintenance task and check the affected projects.
